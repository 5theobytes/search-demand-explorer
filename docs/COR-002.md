# COR-002: keywords must be array[string]

Status: approved by owner (2026-10-07, DECISIONS.md item 6), merged locally.

Decisions (one entry):
1. Dedupe is case-insensitive (`casefold`), first occurrence wins, order preserved, in both `/api/volume` and `/api/discover`.
2. A missing `keywords` key is treated as `[]` (existing "empty" message); a present non-list (including `null`) gets 400 "The keywords field must be an array of strings".
3. The per-endpoint cap (1000 volume / 200 discover) is applied after trim and dedupe.
